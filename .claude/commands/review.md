# /review-agent — Agent Code Review

Reviews a named agent file for correctness against the BaseAgent pattern and migration-specific rules.

## Usage

```
/review-agent [filename or agent name]
```

Example: `/review-agent GmailValidationAgent` or `/review-agent backend/src/agents/gmail/GmailValidationAgent.js`

## What This Command Does

1. Locates the agent file in `backend/src/agents/`
2. Reads the file and `backend/src/agents/core/BaseAgent.js` for reference
3. Checks the following criteria:
   - Extends `BaseAgent` via `const { BaseAgent } = require('../core/BaseAgent')`
   - Constructor calls `super('ClassName')` where string matches the class name exactly
   - Implements `execute(context)`, NOT `run(context)`
   - Uses `logger.child({ agent: this.name, executionId: context.executionId })` as the logger
   - Returns a plain object from `execute()` (not `this`, not a class instance)
   - Exports a class, not a singleton instance (validators/data agents are instantiated in the orchestrator)
   - Non-critical paths catch-and-warn, critical paths re-throw
   - Calendar and contacts validation are correctly gated by `testType` and `context.includeCalendar/includeContacts`
   - `createExecutionLogger` cleanup call is in a `finally` block when used

4. Reports: file path, each check result (PASS/WARN/FAIL), and a recommendation for each WARN/FAIL item

## Checklist Used

```
[ ] Extends BaseAgent
[ ] super('ClassName') string matches class name
[ ] execute(context) implemented — run() not overridden
[ ] Child logger created correctly
[ ] Returns plain object, not this
[ ] Cleanup agents catch-and-warn, never throw
[ ] Validation agents gate calendar: testType === 'E2E' (Outlook) or 'E2E'|'DELTA' (Gmail/GtG)
[ ] Validation agents gate contacts/groups: testType === 'E2E'|'FULL'
[ ] No hardcoded email addresses or credentials
[ ] pdfGenerator is NOT called inside agents (PDF generated by controller on GET /executions/:id/pdf)
[ ] agentBrain.analyzeMigrationLogs() called when result.mismatches.length > 0 (validation agents only)
```
